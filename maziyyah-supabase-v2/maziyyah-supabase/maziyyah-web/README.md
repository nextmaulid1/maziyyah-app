# MAZIYYAH GENERATION (MA28IYYAH)

**A Digital Alumni Community Platform**

Maziyyah Generation (MA28IYYAH) merupakan platform komunitas digital alumni yang dirancang sebagai ruang untuk mempererat hubungan, membangun komunikasi, dan berbagi informasi antaranggota alumni dalam satu lingkungan digital.

🌐 **Live Website:** https://maziyyahgens.netlify.app/

💻 **Repository:** https://github.com/nextmaulid1/maziyyah-app

---

## 📌 About The Project

MA28IYYAH dikembangkan sebagai wadah digital bagi alumni untuk tetap terhubung, saling mengenal, dan berinteraksi meskipun berada di tempat dan aktivitas yang berbeda.

Platform ini mengintegrasikan fitur komunitas, profil anggota, pembaruan informasi, berbagi media, dan komunikasi antaranggota.

## ✨ Main Features

- **Alumni Profiles** — Profil pribadi anggota komunitas.
- **Community Updates** — Berbagi informasi dan pembaruan komunitas.
- **Social Interaction** — Ruang interaksi dan komunikasi antaralumni.
- **Media Sharing** — Berbagi konten dan media.
- **Direct Messaging** — Komunikasi langsung antaranggota.

## ⚙️ Development

Proyek ini dikembangkan menggunakan Visual Studio Code dengan Supabase sebagai layanan backend.

Untuk menjalankan dan mengembangkan proyek, diperlukan:

1. Clone repository.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Siapkan project Supabase.
4. Konfigurasikan Supabase URL dan Publishable Key.
5. Jalankan website melalui local development server.

**Catatan:** Jangan membagikan Supabase Secret Key atau Service Role Key di dalam source code maupun repository publik.
